# stackable-eval

Just a scratch repo to kick the tires on [stackabletech](https://github.com/stackabletech) —
they build Kubernetes operators for data platform stuff (Spark, Kafka, Airflow,
NiFi, Trino, Druid, HBase, HDFS, Hive, ZooKeeper, OpenSearch, Superset...).
Wanted to see if it's a legit place to send a PR someday, so instead of just
reading the docs I deployed one of the operators on a local cluster and ran
an actual job through it.

Nothing here is meant to be reused, it's just notes and the manifest I used.
Writeup is in [FINDINGS.md](FINDINGS.md).
