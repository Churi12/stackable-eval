# stackable-eval

A hands-on evaluation of [stackabletech](https://github.com/stackabletech) —
a company/org building Kubernetes operators for data platform tools (Spark,
Kafka, Airflow, NiFi, Trino, Druid, HBase, HDFS, Hive, ZooKeeper, OpenSearch,
Superset, etc.) — as a potential target for OSS contributions.

This is a throwaway scratch repo, not a real project. Goal: deploy one real
operator (spark-k8s-operator) on a local cluster, poke at the dev/contribution
workflow, and write up findings in [FINDINGS.md](FINDINGS.md) before deciding
whether to invest time opening PRs there.

See [FINDINGS.md](FINDINGS.md) for the writeup.
